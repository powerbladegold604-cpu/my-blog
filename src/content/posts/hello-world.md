## 为什么不用 Spring Boot

我见过太多人想给博客搭一套"完整后端"：Spring Boot + MyBatis + MySQL + 一台服务器。能跑起来，但每加一个功能都要动数据库、改接口、重新部署。

博客的本质是**一堆不会变的文章**。它不需要数据库，不需要登录，不需要后台管理——**它只需要被正确地变成 HTML，然后放在能被访问的地方。**

## 静态站到底省掉了什么

| 传统方案 | 静态站 |
|---|---|
| 租服务器（每月几十到几百） | 免费（GitHub Pages） |
| 装 MySQL，备份，防注入 | 没有数据库 |
| 配 Nginx、开端口、买 SSL | 全部托管服务商搞定 |
| **ICP 备案（国内服务器必须）** | **不需要**（GitHub 托管在境外） |
| 服务器挂了要救 | 静态文件，挂不了 |
| 改一个字要重新部署 | 改一个字，push，30 秒后上线 |

## 它唯一的门槛

**你得会写 Markdown，和会用 Git。**

这两样加起来，比配置 MySQL 连接池简单得多。

> 静态站不是"简化版的后端"，它是"这件事本来就不需要后端"。
